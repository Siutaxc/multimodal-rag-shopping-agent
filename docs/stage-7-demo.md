# ShopLens 三分钟稳定演示流程

## 演示前 30 秒检查

~~~powershell
npm run stack:up
Invoke-RestMethod http://localhost:8000/api/v1/health/ready
~~~

确认返回 `ready`，然后用浏览器打开 `http://localhost:3000`。默认 Fixture Provider 不依赖付费模型或外部端点。

## 三分钟顺序

1. **0:00–0:25：提交默认 Agent 查询**  
   保留“1000 元以内，头戴式，地铁通勤，降噪强，戴眼镜尽量舒服。”，点击“开始导购”。

2. **0:25–0:45：解释硬条件与软偏好**  
   在结果页指出类型、最高价格、币种和 ANC 是数据库硬条件；通勤和佩戴舒适是软偏好。点击条件上的 `×` 可单字段清除。

3. **0:45–1:10：定位证据**  
   在第一件商品的匹配条件或推荐依据中点击“定位证据”。详情页会高亮对应商品事实或评论；评论明确是非可信用户内容，缺失事实显示“暂无可靠数据”。返回结果页。

4. **1:10–1:45：展示图文检索**  
   选择“图片 + 文字”，上传 `data/fixtures/images/fixture-001.png`，输入“找外观相近的黑色款，预算降到 800”，并在最高价格输入 `800` 后提交。指出图片/文字只影响排序，预算仍由硬过滤保证。

5. **1:45–2:15：完成商品对比**  
   在两件商品卡上点击“加入对比”，使用底部对比栏进入对比页。说明统一字段、缺失值和每个单元格的“核验单元格”链接。

6. **2:15–2:40：展示 Query Trace**  
   回到结果页展开检索轨迹，指出词法、文本向量、图片向量、融合、重排候选数、模型版本与耗时。Agent 结果还可打开独立完整轨迹，工具步骤硬上限为 4。

7. **2:40–3:00：展示评测边界**  
   打开 `evals/reports/stage4-text-ablation.md`、`stage5-multimodal-ablation.md` 与 `stage6-agent-evidence.md`。明确多模态和重排存在保留的负结果，当前数字只来自 24 件 Fixture，不代表真实模型或生产质量。

## 现场降级话术

- 图片失败：删除图片后切回纯文本/Agent，确定性商品卡仍可返回；
- Reranker 超时：页面保留 RRF 顺序并显示降级原因；
- Agent 生成超时：结构化检索结果和证据保留；
- 会话过期：最近结果仍可查看，下次提交创建新会话；
- 评论来源不可访问：页面显示引用不可用，不伪造来源。
