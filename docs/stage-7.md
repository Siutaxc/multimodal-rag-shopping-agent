# 阶段 7：完整前端与端到端体验

## 范围

阶段 7 在冻结阶段 3～6 API、Agent Schema、会话语义、证据规则、四步工具上限和评测报告的前提下，完成可稳定现场展示的多路由前端与浏览器体验。没有新增后端事实字段、工具或检索策略，也没有从自然语言回答反向解析商品、价格或引用。

全部浏览器与 API 通信继续使用 HTTP/HTTPS，不使用 WebSocket。浏览器只把不透明 `session_id` 保存在当前设备的 `localStorage`，不会写入公开 URL。

## 页面与主路径

- `/`：导购首页。默认提供三分钟演示查询，并保留 Agent、纯文本、纯图片和图片 + 文字四种入口。
- `/results`：独立结果页。恢复最近一次结构化响应和会话，支持追问、显式硬过滤、条件清除、图片输入、重试、空结果恢复和加入/移出对比。
- `/products/{id}`：商品事实与证据详情。推荐引用直接定位到 `fact-*` 或 `review-*` 锚点；缺失事实和不可访问评论来源均有显式状态。
- `/compare`：2～4 商品统一字段对比。使用原生 `table`、`caption`、列头和行头，每个单元格绑定后端提供的证据 ID。
- `/traces/{id}`：非生产开发轨迹。展示状态机、生效硬条件、白名单工具输入/输出摘要、模型调用、引用校验和降级；页面不展示会话 ID。

站点元数据包含与最终深色/荧光绿视觉一致的 `public/og.png` 社交预览图；部署时通过 `NEXT_PUBLIC_SHOPLENS_SITE_URL` 设置其 HTTP/HTTPS 站点基址。

## 状态与恢复

搜索执行统一使用 12 秒 HTTP 超时，图片上传使用 15 秒超时。UI 区分并提供恢复动作：

- 加载：按钮禁用、`aria-busy`、状态播报和结果骨架；
- HTTP/网络错误：错误状态与“重新提交”；
- 超时：明确提示重试或改用确定性检索；
- 图片错误：提交前校验 MIME/5 MB，支持预览、替代文本、删除和重新选择，服务端错误保留在统一错误区；
- 空结果：按结构化字段清除当前硬条件后重试，不擅自放宽其他条件；
- 部分降级：保留结构化商品卡，状态区和轨迹同时说明原因；
- 会话失效：保留已缓存结果，清除本地失效会话标识，下次提交创建新会话；
- 引用不可用：显示“证据暂不可用”或“引用来源暂不可访问”，不伪造链接。

最近结果、查询草稿、会话标识和对比清单只保存在当前设备。刷新 `/results` 会恢复结构化商品卡，并通过 `GET /sessions/{id}` 校验当前会话；不把浏览器展示值写回商品事实。

## 可访问性与响应式

- 页面提供跳到主要内容链接和语义主导航；
- 表单使用 `fieldset`、`legend`、关联标签、错误说明和 live region；
- 异步完成后焦点移动到结果标题，键盘焦点具有高对比轮廓；
- 商品参数用 `dl`，对比使用语义表格，并提供可横向滚动区域说明；
- 图片预览包含文件名替代文本；评论明确标记为非可信证据；
- 桌面、平板、700 px、430 px 断点均有专门布局；尊重 `prefers-reduced-motion`。

## 浏览器测试

`apps/web/e2e/stage7.spec.ts` 在真实 Chrome 中以确定性 HTTP 响应覆盖：

1. 文本查询并打开商品详情；
2. 纯图片搜索；
3. 图片 + 文字搜索且结果满足预算；
4. 选择两件商品并完成对比；
5. 追问修改预算并在刷新后恢复会话；
6. Reranker 故障后的显式降级结果。

配置对桌面与 Pixel 7 视口各运行一次。`stage7.live.spec.ts` 仅在显式设置环境变量时连接正在运行的 Compose Web/API，执行 Agent、证据详情、图文检索和对比流程。CI 默认路径不依赖付费模型。

## 已知边界

- 当前无账号认证；本地会话标识具有 bearer-like 性质，不应共享浏览器配置或本地存储。
- 商品图片 API 不提供公开图片字节路由，因此结果卡不伪造图片 URL；上传参考图只显示本地 Blob 预览。
- 阶段 4/5/6 默认仍为确定性 Fixture Provider，真实 BGE、SigLIP2 和 LLM 质量未实测。
- 外部 200 商品仍因数据许可不明确延期；阶段 7 只证明 24 件人工 Fixture 的产品与工程链路。
- Playwright HTML 报告和失败轨迹是本地临时产物，已从 ESLint、Docker 构建上下文和版本控制中排除。
