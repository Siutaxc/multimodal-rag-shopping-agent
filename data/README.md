# ShopLens 数据目录

`fixtures/headphones.json` 是专为自动化测试和本地演示人工构造的 24 件耳机数据，采用 CC0-1.0 许可。名称、价格、规格、来源 URL 和评论片段均为虚构信息，不代表真实商品或实时价格。

运行时对象由 `ObjectStorage` 写入 `data/storage/`；该目录被 Git 忽略。在 Docker Compose 中，同一路径由位于 D 盘 Docker 数据根目录中的命名卷持久化。

本仓库不包含 Amazon Reviews 2023 或任何其他外部商品快照。导入首批 200 件外部样本前必须重新确认：

1. 数据集许可和允许的分发方式；
2. 待下载文件的预计大小；
3. 下载与解压位置位于 D 盘；
4. 原始数据不提交到仓库。
